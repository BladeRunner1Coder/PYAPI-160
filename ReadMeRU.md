### Приложение загружает файлы с кошачьими изображениями из https://cataas.com/ и с вашим текстом в вашу папку на Яндекс Диске (https://360.yandex.ru/disk/), а также генерирует и изменяет JSON файл с названиями и размерами загруженых файлов.

#### Приложению необходим OAuth token из https://yandex.ru/dev/disk/poligon/

#### Этот токен должен быть помещён в переменную "token" в модуле "settings.py" (как показано в модуле "settings.example.py".

#### Папка для этих файлов с кошачьими изображениями на вашем Яндекс Диске также создаётся этим приложением. Имя папки содержится в глобальной переменной  "study_group_name".

#### Команда "YD = YandexDisk(token)" создаёт объект "YD" класса "YandexDisk" (с параметром "token"), который позволяет вам использовать его методы.

#### Метод "YD.create_folder(study_group_name)" создаёт папку с названием "study_group_name".

#### Метод "upload_files_to_folder(self, folder_name)" - это цикл, который предлагает ввести текст (который будет добавлен к случайному кошачьему изображению) или цифру 0 (для выхода из цикла). Файл с кошачьим изображением и вашим текстом загружается в вышеупомянутую папку на вашем Яндекс Диске. Названием файла (без расширения) является введёный вами текст. Если название нового файла будет точно совпадать (включая расширение) с названием файла, уже существующего в этой папке на вашем Яндекс Диске, приложение попросит вас ввести другой текст.

#### Метод "upload_files_to_folder(self, folder_name)" вызывает статический метод "get_cat_file_info(file_name, file_extension, image_size)", который отвечает за создание и изменение JSON файла с названиями и размерами файлов, загруженных в вышеупомянутую папку на вашем Яндекс Диске. Все параметры этого статического метода относятся к типу "String". Название JSON файла - "image_size_data.json"

#### Приложение информирует вас об успешном (или нет) выполнении всех важных этапов.
